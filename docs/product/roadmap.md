# Product Roadmap

## Phase 0 – Foundations (Week 1)
- Monorepo scaffolding (web + API) with shared tooling and CI skeleton.
- Draft customer journeys, pricing hypotheses, and legal/compliance checklist.
- Ship marketing landing stub with placement tiers and early access form.

## Phase 1 – Free Canvas MVP (Weeks 2-3)
- Anonymous session tokens + lightweight moderation tooling.
- Canvas interactions: drawing, text notes, history replay, admin clear.
- Real-time event streaming (Socket.IO), optimistic UI, offline buffer.
- Board catalog and selection UX.
- Analytics basics: page views, active creators, post frequency.

## Phase 2 – Monetized Placements (Weeks 4-5)
- Pricing engine with tier definitions (size, position, max duration, surge rules).
- Checkout flow (Stripe test mode), webhooks, ledger + audit log.
- Board owner dashboard: configure pricing, review queue, earnings summary.
- Referral and upsell prompts (“Claim your profile”, “Upgrade board”).

## Phase 3 – Marketplace Acceleration (Weeks 6-7)
- Public board directory with filters, search, sponsorship slots.
- A/B testing harness for pricing/copy, growth experiments.
- Incentives: referral credits, time-limited promos, featured rotating slots.
- Observability upgrades (metrics dashboards, alerting, heatmaps).

## Phase 4 – Scale & Polish (Week 8+)
- Content moderation automation (ML heuristics, abuse reporting workflow).
- Snapshot exports (PNG/PDF), embed widgets, API access for partners.
- Multi-tenant billing, volume discounts, board co-ownership/teams.
- Performance hardening, load testing, failover strategies.

## Product Principles
1. **Frictionless Creation** – Always allow instant anonymous posting with strong guardrails.
2. **Earned Upgrades** – Monetization enhances experience (placement boosts, analytics), never blocks participation.
3. **Board Owner Success** – Tools that help hosts earn, moderate, and grow communities.
4. **Transparency** – Clear pricing, visible availability, honest revenue share disclosures.
